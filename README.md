# 웹툰 이미지 비교 프로그램 (Webtoon Comparator)

웹툰 제작 과정에서 콘티, 작화, 배경 이미지 등의 세로 스크롤을 동시 비교하고 검수하기 위한 윈도우 전용 데스크톱 프로그램입니다.

## 주요 기능
1. **세로 스크롤 동시 비교**: 콘티, 작화, 배경 등 각 슬롯에 이미지를 올려 한 번의 스크롤로 동시 비교
2. **숫자 기준 자동 정렬**: 이미지 파일명 내 숫자를 인식하여 오름차순(`001`, `002`, `003`...) 자동 정렬
3. **가로 슬롯 개수 조절**: 메인 2개를 기본으로 1개~5개까지 자유롭게 조절
4. **일괄 비율 크기 조절**: 슬라이더를 통해 모든 이미지의 표시 비율(10%~100%)을 한 번에 조절
5. **드래그 앤 드롭 및 파일 열기**: 이미지 드래그 앤 드롭 또는 클릭하여 일괄 파일 열기 지원

## GitHub에서 EXE 빌드 방법
1. 본 압축 파일의 압축을 해제합니다.
2. GitHub 저장소(Repository)에 전체 파일 및 폴더를 업로드합니다. (`.github` 폴더 포함)
3. GitHub 상단의 **Actions** 탭으로 이동하면 깃허브 서버가 자동으로 `.exe` 파일을 빌드합니다.
4. 빌드가 완료되면 **Artifacts** 영역에서 `WebtoonComparator-Setup` 파일을 다운로드하여 실행합니다.
